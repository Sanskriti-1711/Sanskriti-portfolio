CVE Summarisation Agent

Retrieval / NLP / NVD data

NVD records are dense and inconsistent; triage needs relevant context quickly, including impact, affected parts, and direction. This project retrieves relevant CVEs, structures their context, and generates concise summaries using semantic similarity search.

The design is retrieval-first: make source information easier to navigate before asking a language model to explain it.
