## Direction contract

**THESIS:** An evidence casebook wired like a Linux investigation console: recruiters can trace each work theme to concrete project, experience, and writing evidence. It refuses both the generic neon hacker dashboard and the interchangeable project-card grid.

**OWN-WORLD:** Graphite (#101714), terminal green (#a8d977), evidence blue (#6fa8c6), warm dossier paper (#f2ead8), and rust investigation marks (#db6b50). Use a clear editorial display face, readable sans-serif copy, and monospace only for real file metadata, paths, and status. Terminal surfaces frame real evidence plates; branching neural-network traces make the AI focus visible while connecting actual portfolio destinations. No fake command prompt or invented system status.

**STORY:** A recruiter understands Sanskriti's applied-AI and engineering focus, follows connections from work themes to project, experience, and writing evidence, then opens a CV, repository, or contact link. The node map indexes portfolio relationships; it does not depict a model architecture.

**FIRST VIEWPORT:** A compact graphite command rail frames a two-column opening. The left gives role, thesis, location, and CV/contact actions with terminal-style labels; the right treats the large virtual try-on dissertation image as a warm evidence plate with file metadata. A branching neural-network-style evidence graph links retrieval, vision, production, security, and writing directly to their real sections; its paths describe portfolio relationships, never a model architecture. The primary action is “Explore selected work.”

**FORM:** The Evidence Casebook, first of the three hacker–detective directions shown; selected by the user and now tuned to make both halves legible. Seed key: `bfb8c737`. Signature interaction: activating a map node traces a short signal path to its evidence and keeps the selected route marked; no content is hidden. Motion is limited to that route trace, with a reduced-motion fallback.
